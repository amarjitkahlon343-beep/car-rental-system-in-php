# 🚗 Car Rental System

A web-based Car Rental System built with PHP and MySQL.

## Features
- User registration and login
- Browse available cars
- Book and cancel rentals
- Admin panel to manage cars and bookings

## Tech Stack
- PHP
- MySQL
- HTML / CSS
- JavaScript

## How to Run
1. Install XAMPP or WAMP
2. Import the database SQL file into phpMyAdmin
3. Place project folder in `htdocs/`
4. Open browser: `http://localhost/car-rental-system`
